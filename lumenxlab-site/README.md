# LUMEN-X Lab website

This is a static GitHub Pages website for `lumenxlab.org`.

## Replace placeholders

- Replace `images/lumenx-logo.png` with the final LUMEN-X logo.
- Replace `images/banner.jpg` with the final social/website banner.
- Add member images to `images/members/`.
- Update publication, project and news entries.

## Local preview

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Publish

```bash
git add .
git commit -m "Build LUMEN-X website structure"
git push origin main
```
