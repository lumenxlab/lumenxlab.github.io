About

Alekhya Gorrela is a doctoral researcher in the Internet of Things, with a focus on LoRaWAN and low-power wide-area networks. Her work addresses network-performance optimisation, energy efficiency and resource allocation for large-scale IoT applications through simulation-based analysis and protocol-level optimisation.

Supervisors

Prof. Nikumani Choudhury, BITS Pilani, Hyderabad Campus.

Research Interests and Technical Focus

Research topic: Exploiting Adaptive Data Rate Technique for Longer Network Lifetime and Resource Allocation of LoRa-Based IoT Applications.

  • Internet of Things and large-scale IoT applications
  • LoRa and LoRaWAN communication systems
  • Low-Power Wide-Area Networks
  • Adaptive Data Rate optimisation
  • Channel Activity Detection
  • Energy-efficient resource allocation
  • Network lifetime, reliability and scalability

Research Objective

This research focuses on improving the performance and energy efficiency of LoRa-based IoT networks using the Adaptive Data Rate technique. The work aims to extend network lifetime and optimise resource allocation for large-scale IoT applications.

It also evaluates the effect of Adaptive Data Rate and Channel Activity Detection mechanisms on communication reliability, latency, scalability and overall network performance.

Projects, Tools and Evaluation

  • Simulation of LoRaWAN networks using NS-3 and MATLAB.
  • Implementation and evaluation of Adaptive Data Rate mechanisms in simulated LoRaWAN environments.
  • Evaluation of Channel Activity Detection mechanisms.
  • Performance analysis using energy consumption, packet delivery ratio, latency, reliability and network lifetime.
